## Descripción del Proyecto
Este sistema busca reemplazar el proceso de registro manual en papel por una plataforma digital estandarizada que automatiza la recepción, validación de identidad (DNI/RUC), asignación correlativa de código (MP-00X) y consulta de trámites, en cumplimiento de la Ley N.° 31170 y el D. Leg. N.° 1412.

## Estructura del Repositorio
* pseudocodigo_mesa_de_partes.psc: Algoritmo desarrollado en PSeInt con control de bucles, validación de datos y banderas de cancelación.

## Ejecución
El proyecto actual se ejecuta abriendo el archivo `pseudocodigo_mesa_de_partes.psc` desde el entorno PSeInt para su simulación y pruebas.
